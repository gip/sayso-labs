# generated/

This directory is auto-generated by `packages/protocol/scripts/generate-payload-types.ts`.

Do not edit by hand. To refresh:

```bash
pnpm --filter @sayso-labs/protocol gen:types
```

The generator runs as a `prebuild` step, so a normal `pnpm --filter @sayso-labs/protocol build` rebuilds these files.

## Relationship to `src/types.ts`

- The JSON Schemas in `skills/sayso-*/SKILL.md` are the canonical wire contract.
- `generated/payloadTypes.ts` mirrors those schemas exactly (deep-inlined, no shared sub-types).
- `src/types.ts` is the hand-written developer-facing API — uses shared types like `SkillPacket`, `AgentSkillContract`, etc.

The two are kept aligned by `payloadTypes.driftCheck.ts`, which asserts that every payload type in `types.ts` is structurally compatible with the generated wire schema. If the schema in a SKILL.md changes, either:

1. Re-run `gen:types` and update `types.ts` to match, or
2. Update the SKILL.md schema and re-run `gen:types`.

A `tsc` failure in `payloadTypes.driftCheck.ts` means types.ts has drifted from the canonical schemas.
